# Data Analytics

## Finalidade
Organizar estudos e projetos de análise de dados, desde a preparação até a interpretação e comunicação dos resultados.

## Arquivos esperados
- Notebooks, scripts, consultas SQL e documentação.
- Conjuntos de dados públicos ou anonimizados e relatórios analíticos.
- Não incluir dados pessoais, confidenciais ou sem autorização de uso.

## Ferramentas relacionadas
Python, SQL, Excel e ferramentas de visualização, conforme aplicável.
