# Design editorial

## Finalidade
Organizar projetos de diagramação e comunicação visual editorial.

## Arquivos esperados
- PDFs de apresentação ou publicação, imagens de páginas e materiais de referência autorizados.

## Ferramentas relacionadas
Ferramentas de diagramação editorial e edição gráfica, especificadas em cada projeto quando pertinente.
