# Recursos visuais dos projetos

## Finalidade
Reunir imagens e materiais gráficos associados aos projetos, separados dos arquivos-fonte de cada trabalho.

## Arquivos esperados
- Capas, thumbnails, diagramas, ilustrações e imagens de apoio.
- Renders e imagens de apresentação; sempre que possível, usar nomes que indiquem o projeto relacionado.

## Ferramentas relacionadas
As ferramentas variam conforme o projeto e podem incluir Power BI, editores de imagem, ferramentas de diagramação e Blender.
